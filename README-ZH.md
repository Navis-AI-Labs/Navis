## 概述

Navis 是面向产物的持久化协作框架。

它适用于代码开发、市场调研、产品设计、法律文件等需要 Human 与 Agent 持续协作，并最终交付成果的工作。

传统 AI 协作通常以 **Agent / Session** 为中心，Session 结束后，项目的上下文、经验与产物也容易随之割裂。

Navis 将协作主体转向 **Project**：

> **Project 是持续存在的主体，Agent 是临时执行单元。**

Agent 进入 Project 工作，完成后将成果与经验沉淀回 Project。Agent 可以更换，Session 可以结束，但 Project 会持续。

## 核心

* **Project 持续** — 承载目标、状态、知识、经验与产物，保持项目连续性。
* **认知积累** — 每一次协作都会为 Project 留下新的知识与经验，使项目越来越了解自己。
* **Human × Agent** — Human 提供方向与判断，Agent 负责执行，共同推进项目。
* **生态形成** — 产物、知识、经验与工作方式不断沉淀并相互作用，逐渐形成属于 Project 自己的协作体系。
* **产物导向** — 所有积累最终服务于一个目标：持续产出可交付的成果。

---

## 设计原则

* **Project 为主体** — 项目的连续性不依赖某个 Agent 或 Session。
* **产物为目的** — 系统最终服务于真实、可交付的成果。
* **经验可积累** — 过去的工作成为下一次工作的基础。
* **Human 与 Agent 共事** — Human 参与过程，而不是只在结果出现后审批。
* **Agent 可替换** — Agent 可以离开，但它留下的成果与经验属于 Project。
